### 8.- Solicitar un número entero **X**. Mostrar por pantalla **X números aleatorios entre 1 y 100**.

Para generar números aleatorios en JavaScript:
- `Math.random()` genera un número decimal aleatorio entre **0 y 1** (sin llegar a 1).
- `Math.random() * 100` genera un número decimal entre **0 y 100**.
- `Math.floor(...)` elimina la parte decimal redondeando hacia abajo.
- Por tanto, `Math.floor(Math.random() * 100) + 1` genera un número entero aleatorio entre **1 y 100**.

Utiliza un bucle `for` para generar y mostrar tantos números aleatorios como indique **X**.


### 40.-  
Solicitar un número entero. Sumar todos los dígitos del número.
let numero = Number(prompt("Introduce un número entero:"))
let suma = 0
let digitio = 0
while (numero > 0) {
    digito = numero % 10
    suma = suma + digito
    numero = Math.floor(numero / 10)
}

console.log("La suma de los dígitos es " + suma)
